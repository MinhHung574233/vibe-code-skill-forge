# Localisation (English and Vietnamese)

SkillForge ships two languages: English (the source language) and Vietnamese. Settings → Language
offers Auto (follow the device), English and Tiếng Việt. The choice is kept in `localStorage`
(`sf-lang`) so it is known before the database opens.

## How it works

- `src/i18n/core.ts` is pure TypeScript: `t(source, params?)`, `intlLocale()`, language state.
- The **English source string is the key**. `t('Start')` returns the Vietnamese text in Vietnamese
  and the key itself in English. A missing entry falls back to English, never to a blank.
- Dictionaries are plain objects in `src/i18n/vi/<area>.ts`, merged by `src/i18n/vi/index.ts`.
  Each area file is owned by one part of the app so edits do not collide.
- `LanguageBoundary` (in `main.tsx`) remounts the app when the language changes, so every screen
  re-renders. Call `t()` at render time or inside functions, never in a module-level constant that
  runs once at import. Keep English in the constant and call `t(label)` where it is shown.
- `src/i18n/i18n.test.ts` parses every source file with the TypeScript compiler and fails when a
  literal `t('...')` key has no Vietnamese entry, or when `{placeholders}` differ.
- Bundled content (lessons, tips, vocabulary hints, puzzle text) is translated the same way: the
  English text in the data is the key, and `t(text)` is called where it is rendered. Content tests
  use `missingTranslations(strings)` from `src/i18n/testing.ts` to prove nothing was forgotten.

## Writing keys

- Use the exact English string. Use `{name}` placeholders and pass `params`:
  `t('{count} words', { count })`. Never build a sentence by joining translated pieces.
- English plurals: write two keys and choose in code:
  `n === 1 ? t('{n} word', { n }) : t('{n} words', { n })`. Vietnamese has no plural; give both
  keys the same wording.
- Do not translate: code, commands, file names, notation (`R U R'`), product names (SkillForge,
  Git, IntelliJ, Spring Boot), chess algebraic notation, stored ids, or the Vietnamese meaning
  already stored in the vocabulary.
- A string that is the same in both languages (for example `Git`) still gets an identity entry.
- Dates and numbers: use `intlLocale()` for `Intl` formatters.

## Vietnamese style

Address the learner as **bạn**, in a friendly, direct tone, with short sentences. Keep common
English technical terms when Vietnamese developers say them in English (commit, branch, build,
API, XP, streak is translated). Glossary:
